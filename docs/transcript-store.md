# Общее хранилище транскрипций

Единственный источник формата для Folder-video, Окошка и YouTube Radar. Менять формат только здесь и синхронно во всех приложениях. Эталонная логика — `src/shared/transcript-store-core.js` (в Окошке и Radar — TypeScript-порт `transcriptKeys.ts` / `transcript-keys.ts`), эталонные файлы — `tests/fixtures/transcript-store/`.

## Папка

- Настройка «Папка транскрипций» в каждом приложении; по умолчанию `Documents\Transcripts`.
- Папка плоская, подпапок нет. Все файлы одного источника имеют общее имя (stem).
- Папка окружения распознавания (`transcribe.dll`, модели) — отдельная настройка, по умолчанию `%LOCALAPPDATA%\transcribe-shared`.

## Имя файлов (stem)

Один ролик — один набор файлов во всех приложениях. В имени только ключ; название видео хранится в манифесте.

| Источник | Stem |
| --- | --- |
| Ролик YouTube | `yt-<id>` (id — ровно 11 символов `[\w-]`) |
| Изменённая копия ролика (перевод, ускорение) | `yt-<id>.<вариант>`, например `yt-dQw4w9WgXcQ.RU_2x` |
| Локальное видео без известного ролика | `file-<первые 16 символов SHA-256 содержимого файла>` |

Вариант — язык и/или скорость: `RU`, `RU_2x`, `UK_1.5x`, `2x`. Язык заглавными, скорость `1x` в метке не пишется. Копия без языка и скорости — оригинал и пишется в `yt-<id>`. Вариант без скорости (`RU`) в Windows совпадает по имени файла с переводом Radar `yt-<id>.ru.*` и перезаписывает его: это принято.

Код ролика берётся в порядке: метаданные файла (`purl`, `comment`, `description`, `source` со ссылкой YouTube) → `[<id>]` в имени файла (`Название [dQw4w9WgXcQ] (RU)_2x.mp4`) → ссылка, вписанная в Folder-video (свойство файла или метаданные Folder-video). Эвристик (сопоставление по названию, логи) нет. Вариант берётся из тега `variant` метаданных файла, для старых файлов — из имени (`(RU)` и `_2x`).

Старое имя `<имя>__<первые 12 символов SHA-256 пути>` только читается и переносится (см. «Перенос»). Хэш содержимого — полный SHA-256 файла; приложения кэшируют его по `путь|размер|mtime`.

## Файлы

| Файл | Содержимое |
| --- | --- |
| `<stem>.srt` | Транскрипция (фразы с таймкодами) |
| `<stem>.txt` | Тот же текст без таймкодов |
| `<stem>.json` | Манифест (ниже) |
| `<stem>.ru.srt`, `<stem>.ru.txt` | Русский перевод (создаёт YouTube Radar) |
| `<stem>.summary.json` | Сводка ИИ |
| `<stem>.notes.md` | Заметки с таймкодами |
| `<stem>.lock` | Признак идущей транскрибации |

Запись всегда атомарная: во временный файл `<файл>.<pid>.tmp`, затем `rename`.

## Манифест

Версия 3:

```json
{
  "version": 3,
  "source": { "kind": "file", "path": "D:\\v\\a.mp4", "size": 1000, "mtimeMs": 1700000000000, "sha256": "…", "youtubeId": "необязательно" },
  "variant": { "label": "RU_2x", "language": "ru", "speed": 2 },
  "transcript": { "model": "parakeet-tdt-0.6b-v3-Q8_0.gguf", "engine": "parakeet-tdt", "language": "необязательно", "createdAt": "ISO", "createdBy": "folder-video|okoshko|youtube-radar" },
  "translations": { "ru": { "createdAt": "ISO", "createdBy": "youtube-radar" } }
}
```

`variant` есть только у копий ролика. Для ролика без файла `source` — `{ "kind": "youtube", "id", "url", "title" }`. Манифесты версий 1 (`filePath`, `size`, `mtimeMs`, `modelPath`) и 2 читаются; версия 3 пишется при следующей записи или переносе.

## Актуальность

- Транскрипция локального видео актуальна, пока совпадает `sha256` (если он есть и в манифесте, и у видео); иначе — пока совпадают путь, размер и mtime. Модель и приложение не сравниваются, перегенерация — вручную.
- Манифест `kind: "youtube"` (транскрипция ролика от Radar или Окошка) подходит локальному видео без изменений; у копии — только набор с её вариантом.
- Сводка устарела только при изменении текста транскрипции (`transcriptHash` — SHA-256 содержимого `.srt`). Модель ИИ записывается, но не сравнивается.

## Перенос

Folder-video и Окошко переименовывают набор лениво, при открытии видео (а Folder-video — ещё и кнопкой «Перенести все» в настройках):

1. Набор со старым именем (по хэшу пути) → `file-<хэш>` или `yt-<id>[.<вариант>]`; манифест приводится к версии 3, путь в манифесте и сводке обновляется.
2. Набор `file-<хэш>` → `yt-<id>`, когда код ролика стал известен.
3. Видео перенесли: тот же размер и mtime, другой путь, старого файла уже нет — набор со старым именем находится по манифесту. Неоднозначные совпадения пропускаются.

Существующие файлы нового имени не перезаписываются. Если файлы уже есть, набор остаётся как есть и попадает в список неперенесённых Folder-video с причиной (`transcripts-unmigrated.json` в данных приложения); оттуда его можно перенести вручную («Указать видео», «Повторить»). Заметки без транскрипции (нет манифеста) при переносе не находятся.

## Сводка (`.summary.json`)

```json
{ "version": 1, "filePath": "…", "size": 0, "mtimeMs": 0, "transcriptHash": "…", "model": "провайдер/модель или имя модели", "summary": { "overview": "…", "topics": [ { "title": "…", "description": "…", "start": 12.5 } ] } }
```

У ролика YouTube `filePath/size/mtimeMs` отсутствуют. Запрос к ИИ, нарезка на пакеты и нормализация — как в `src/main/summary-core.js`.

## Заметки (`.notes.md`)

Блоки, разделённые строкой `---`; первая строка блока — `[м:сс]` или `[ч:мм:сс]`. Разбор — `src/shared/notes-core.js`. До 1 МБ; пустой текст удаляет файл.

## Lock

`<stem>.lock`: `{ "app": "okoshko", "pid": 4242, "startedAt": "ISO" }`. Пока lock живой, другие приложения не запускают транскрибацию этого источника и показывают «Транскрибация уже идёт в <приложение>». Lock устарел, если процесса `pid` нет или прошло более 6 часов; устаревший lock удаляется.

## Копия ролика у онлайн-ролика

Если у ролика (Radar, Окошко) нет своего набора, но есть набор копии `yt-<id>.<вариант>`, приложения показывают его только для чтения (транскрипция, сводка, заметки) с пометкой «копия <вариант>»; русский вариант предпочтительнее. Время приводится к оригиналу умножением на скорость варианта (приблизительно). Свои заметки и сводка ролика пишутся в `yt-<id>.*`.

## Распознавание

Все приложения вызывают `transcribe.dll` через koffi в отдельном процессе; звук берётся из системного `ffmpeg` (`PATH`) потоком f32le 16 кГц кусками по 15 с. Слова собираются во фразы (`wordsToPhrases`): разрыв при паузе более 1 с или длине более 30 с, закрытие на `. ! ? …`.

## Video-translate

Программа перевода записывает код ролика и вариант в файл: имя `Название [<id>] (RU)_2x.mp4`, теги `purl`/`comment` (ссылка) и `variant` (`RU_2x`), mp4 пишется с `-movflags use_metadata_tags`.
